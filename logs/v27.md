# v27 (versionName 1.1.0) — 2026-09-14

Ports the iOS 1.1.0 feature set (attendance, Apple Health, workout dashboard) to
Android. Requires the backend attendance endpoints in production, plus Play
Console declarations for Health Connect (health data) and foreground location.

## Added
- **Apple Health steps (Health Connect).**
  - Workout home: a daily steps card showing a smooth cumulative curve through the
    selected day (0 / 5k / 10k axis), following the day you swipe to.
  - Stats: a weekly steps bar chart with tap-to-inspect (tap a bar for that day's
    count and date).
- **Workout home dashboard.** Each planned session is its own expandable card
  (title + Start + quick-log + an expand toggle → exercises in one bordered group).
  Empty upcoming days show a "Plan your session" card with a one-tap **copy last
  week's workout**; empty past days show steps or a "No data for this day" state.
  Steps and book cards can be pinned above the workout via long-press.
- **Booking from the workout home.** A "Book a session" card surfaces up to 3 of the
  coach's next available slots with open-spot counts, plus a "Today's booked
  session" section.
- **Gym attendance / check-ins (athlete).** Scan a gym QR (geofence-checked) or the
  coach's rotating session code to check in, then check out; a live "checked in"
  card and month-grouped history. Export the history as a branded PDF (period
  picker + in-app preview + share). Reached from Profile → Gym Check-In.
- **Coach attendance tools.** A Check-Ins hub (Team tab) with a rotating **Session
  Code**, **Gyms** management (add at current location, QR poster sheet, delete), and
  an **Attendance** roster grouped by date, exportable as a per-athlete PDF.

## Changed
- **Week identifier pinned to ISO-8601** (Monday-first) instead of the device
  locale, so week keys match across regions and iOS. Fixes Sunday sessions going
  missing on US-style locales (Sunday landed in the next week's bucket).
- Booking now lives in the dashboard "Book a session" card — removed the redundant
  nav-bar book button (matches iOS).
- Attendance screens use a collapsing large-title (big title scrolls into an inline
  nav-bar title).
- Free-trial copy only shown when a trial is actually offered and the user is
  eligible.

## Fixed
- **Stale cross-week data** on day-swipe — a past session (and its "completed"
  report) could bleed onto a future date. Repaint the correct week's cache on a
  week change, and scope the completed-session match to the logged date.
- **"Copy last week" duplicated sessions** on a double-tap — it now replaces the
  day and guards re-entry.
- **Check-in location** no longer sends a stale last-known fix to the geofence
  (fresh high-accuracy fix; only fall back to last-known when it's recent).

## Dependencies
- Added Health Connect (`androidx.health.connect:connect-client`), fused location
  (`play-services-location`), and Guava (resolves a `ListenableFuture` clash Health
  Connect introduced with CameraX).
